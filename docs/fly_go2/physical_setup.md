# Физические условия и оборудование эксперимента

Арена из нескольких Unitree Go2 с индивидуальным контроллером на урезанном коннектоме
грибовидного тела Drosophila (`artifacts/connectome_mb_v1.*`).  
Внешняя система только задаёт стимулы/условия и анализирует логи
(см. `docs/fly_go2/design_constraints.md`).

---

## 1. Минимальный состав оборудования

### Роботы
- **3× Unitree Go2 Pro или Edu** (с LiDAR L1). Air без лидара — только для одиночных indoor-тестов.
- Запасные батареи / зарядные станции: считать **~1–1.5 ч** активного эпизода на заряд.
- На каждой собаке: уникальный **AprilTag** (family `tag36h11`) на корпусе сверху/сзади, контрастный фон.

### Вычислитель арены (внешнее)
- Ноутбук/мини-ПК: Ubuntu 22.04/24.04, ≥16 GB RAM, Wi‑Fi 5/6.
- Роль: раздача `episode config`, start/stop, e-stop, запись телеметрии, offline-метрики.
- **Не** считает social policy и **не** шлёт peer-learning сигналы.

### Сеть
- Отдельный Wi‑Fi роутер (не гостевая сеть офиса), канал 5 GHz предпочтителен.
- Статические IP: `go2_1…n`, arena PC.
- Отдельный канал/кнопка **E-stop** (пульт Unitree + программный `/arena/e_stop`).

### Стимулы среды
- Пол с матовой разметкой зон **A** (штраф) и **B** (награда): цветная лента / винил / краска.
- AprilTag или QR у зон A/B (как в `configs/examples/room_v1.yaml`).
- Хорошее **равномерное освещение** без сильных бликов на полу (критично для камеры и тегов).
- Мягкие барьеры по периметру (поролон / низкие ограждения) + virtual fence в софте.

### Опционально, но полезно
- Потолочная/угловая камера обзора для видеозаписи эпизодов (только анализ, не обучение).
- Внешний дисплей dashboard.
- ИБП для роутера и PC.

**Доп. лидары не обязательны**, если Go2 Pro/Edu со штатным L1.

## 2. Помещение

| Параметр | Рекомендация |
|---|---|
| Площадь | ≥ **4×5 м** чистой площади для 3 собак; лучше 5×6 м |
| Пол | Ровный, сухой, без порогов; матовый (не глянцевый ламинат) |
| Уклон | Минимальный; без ям и кабелей |
| Температура | **15–30 °C**, без перегрева батарей |
| Влажность | Обычная комнатная; без конденсата на линзах |
| Свет | 300–500 lux равномерно; избегать контрового солнца в камеру |
| Акустика / люди | Ограничить посторонних; яркая одежда операторов может путать детект |
| GNSS | Не нужен (indoor) |

Стартовые точки агентов — разные углы/линия, ≥1 м друг от друга.

---

## 3. Зоны и стимулы

Пример из конфига:
- Зона **A**: `reward: -1` (aversive)
- Зона **B**: `reward: +1` (appetitive)
- Физический размер зоны: порядка **1×1 м** (чтобы вход был однозначным)
- Между A и B — свободное пространство для Explore

Награда/штраф в обучении считаются **на роботе** из одометрии + копии полигонов, не «кликером оператора» (оператор может только менять условия между эпизодами).

---

## 4. Безопасность

- `max_speed_mps ≤ 0.6` на первых сессиях.
- `robot_clearance_m ≥ 0.8` между центрами корпусов.
- Всегда живой оператор с E-stop в зоне видимости.
- Убрать хрупкие объекты, провода, жидкость.
- Не оставлять собак без присмотра при online пластичности (неожиданные политики Avoid/Approach).

---

## 5. Программный стек на площадке

На каждой Go2:
- Unitree SDK / sport+nav режим для локомоции
- Локальный рантайм `connectome_mb_v1.npz`
- Детект AprilTag (свои + зоны), лидар anti-collision
- Локальный расчёт `r` и пластичность KC→MBON по DAN-маскам

На PC:
- `configs/examples/room_v1.yaml` (или свой)
- Логгер телеметрии → `logs/episode_XXX/`
- Анализ: PI, peer_exposure, blind vs sighted

Данные мозга в репо:
- `artifacts/connectome_mb_v1.npz` (+ neurons/edges/manifest)
- Сырые аннотации: `data/flywire/raw/`
- Полный feather связей (~813MB) — скачать скриптом при необходимости пересборки

---

## 6. Типовой день эксперимента

1. Зарядка, AprilTag на местах, свет, роутер.
2. Калибровка карты арены / стартовых поз.
3. `set_config` + hash → `episode_start` (20 мин).
4. Режим `multi_independent` (sighted).
5. Контроль `multi_blind_peers` тем же layout.
6. Выгрузка логов, сравнение `blind_vs_sighted_delta`.

---

## 7. Чего не хватает «из коробки» у Go2

| Нужно для эксперимента | Есть на Go2? | Решение |
|---|---|---|
| Ходьба / обход | Да (Pro/Edu) | Штатный стек |
| Камера для меток | Да | AprilTag детектор |
| Лидар | Да (Pro/Edu) | Spacing / collision |
| Запах / химия | Нет | Не требуется: зоны/теги |
| Отдельный «мозг-мухи» HW | Нет | NPZ на CPU бортового компьютера |
| Social radio между собаками | Не использовать | Только зрение/лидар особи |

## 9. Симулятор перед железом

Перед комнатой с Go2 можно прогнать тот же процесс на Windows:

```powershell
pip install -r requirements-sim.txt
python -m sim.run_sim --seconds 120
python -m sim.run_sim --headless --move-zones --seconds 90
```

См. `sim/README.md`. Зоны в симе — виртуальные полигоны; флаг/`M` имитирует движущуюся проекцию.

Не фиксированные цены, а состав:
- 3× Go2 Pro/Edu + зарядки
- Роутер + Ubuntu PC
- Комплект AprilTag (печать) + разметка пола
- Мягкие барьеры
- Опционально: потолочная камера записи

Итого по железу эксперимент упирается в **наличие 3 собак и комнаты**, а не в спецлабораторию нейробиологии.
